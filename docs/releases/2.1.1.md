# MagicDesk 2.1.1

## Shroot Storage

- Format 17 establishes the persistent-storage compatibility baseline. Storage
  format, metadata revisions and image-import cache identity are now independent,
  so supported metadata updates can preserve installed environments and shared
  layers instead of requiring a fresh import.
- Metadata upgrades run transactionally before use, outside filesystem syscall
  paths. Interrupted upgrades can be retried; updates requiring exclusive access
  report busy while the storage is in use. Unknown newer revisions are rejected.
- Normal startup uses lightweight schema checks, not a full integrity scan.
  Listing environments and applications does not modify the storage schema.
- Verified on-device with fresh Alpine: package installation, shared-layer
  copy-on-write, file metadata and hardlinks, repeated login, and backup/restore
  into an independent library.

**Before updating:** formats 14-16, including the format used by 2.1.0.2, are not
migrated. Export needed guest files with the matching previous version before
recreating those environments. Existing stores are never automatically deleted.
Environments already using format 17 are retained. Android applications and
ordinary MagicDesk settings are unaffected.

This release includes all fixes from 2.1.0.2.
