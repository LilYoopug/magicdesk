# MagicDesk 2.1.0.2

- Improved Shroot filesystem and event-processing performance, with explicit
  durability barriers and batched backing-file allocation. Fixed FIFO ownership
  that could prevent overlay storage from being released.
- Compatibility reports now retain application crash stacks and package versions,
  with clearer evidence for fullscreen transitions.
- Added spacing below Start search and renamed the per-app display setting to
  **App scale**.

**Shroot storage:** this release uses inode-store format 16. Older stores are
not migrated and must be recreated. Export needed guest files with the previous
version before updating. Android applications and ordinary MagicDesk settings
are unaffected.
